## Learning Path

A practical progression through this collection:

1. **Build enumeration skills**  
   Start with Napping Through Enumeration and URL Unlocked.

2. **Study SSH and network communication**  
   Continue with SSH Sleepwalk and Netcat Nightshift.

3. **Understand credential security**  
   Work through Napping Credentials and the credential-focused tabnabbing challenges.

4. **Explore tabnabbing**  
   Study Sleepy Tabnabbing, Tabnabbed Credentials, Tabnab Harvest, and Tabnapped at Dawn.

5. **Investigate authentication**  
   Complete Tabnapped Login Forge to examine login-related security concepts.

6. **Study post-capture and pivoting concepts**  
   Finish with Post-Capture Panic and Python HTTP Pivot.

## How to Use the Labs

- Use every lab only in an authorized CTF or cybersecurity training environment.
- Start with structured enumeration before investigating access or credential-related clues.
- Treat all discovered credentials as controlled lab data.
- When studying SSH and Netcat, understand the purpose of each connection and service.
- For tabnabbing challenges, focus on the underlying web-security issue and appropriate defenses.
- Study Python HTTP pivoting as a controlled networking concept rather than applying it to unauthorized systems.
- Document findings, evidence, and defensive recommendations after each challenge.
